# Nature's Platter - L1B11A3

A modern and responsive grocery store landing page built with HTML5, Tailwind CSS, and daisyUI. The project presents fresh groceries, services, promotional offers, popular products, and a clean shopping-focused interface.

## Overview

Nature's Platter is a frontend grocery shopping experience designed around simplicity, freshness, and accessibility.

The interface includes a responsive navigation bar, promotional hero section, service highlights, product cards, discount offers, and additional shopping sections.

## Features

* Responsive navigation
* Mobile-friendly menu interface
* Hero section with promotional messaging
* Grocery and fresh produce presentation
* Services section
* Popular products section
* Product ratings and pricing

* Responsive product grid

## Getting Started

### Prerequisites

No backend or package installation is required.

You only need:

* A modern web browser
* A code editor such as VS Code

### Run Locally

Clone the repository:

```bash
git clone https://github.com/mrshanshuvo/natures-platter.git
```

Move into the project directory:

```bash
cd natures-platter
```

Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.
